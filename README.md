# Quan Tran Lab

Personal portfolio of Trần Mạnh Quân.

## Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- Sanity-ready content structure
- Vercel deployment

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3001`.

## Production

Primary domain: `https://quantranlab.com`

The first release focuses on the personal portfolio: Home, Work, Project detail, About and Contact. Blog, Templates and Services will be added later.
